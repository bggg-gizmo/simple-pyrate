# Simple Pyrate user guide

[Back to the README](../README.md) · [Troubleshooting](TROUBLESHOOTING.md)

## Install and launch

Use Windows PowerShell 5.1 and .NET Framework 4.8 on 64-bit Windows 10 or 11. Extract the Windows ZIP to a folder you control and launch [`Start-Simple-Pyrate.cmd`](../Start-Simple-Pyrate.cmd) without running it as administrator. Keep all of the source and artwork beside it. The launcher uses a per-process PowerShell execution-policy override without changing user or machine policy. An administrator’s Group Policy can still block it.

On a first launch with missing tools, choose **Install missing tools** or defer with **Later**. If you defer, open **Shipyard** when ready. Jobs waiting for tools can start after successful setup. Only the separate tool setup requests administrator rights.

## Scope and output

1. Paste complete HTTP or HTTPS links, one per line.
2. Choose **Single item per link** to process one item per link. A playlist-only link in this mode processes its first entry.
3. Choose **Playlist / full channel** to let yt-dlp enumerate the supported collection. Use the main YouTube channel URL for the full available channel haul. URLs ending in `/videos`, `/shorts`, or `/streams` select that tab. If a source cannot enumerate a profile, use a batch of direct item links.
4. Select **MP4**, **MP3**, or **Transcript**, in any combination. Each URL is one queue row, and each selected output is a separate pass.
5. Click **Queue haul**. Check **The deck** for speed, ETA when available, item numbers, and final status.

MP4 saves video and includes audio when the source has it. Choose **Best available** or a 480p, 720p, 1080p, 1440p, or 2160p cap. MP3 saves audio only, with 128, 192, or 320 kbps, or best variable bitrate as encoding options.

## Transcripts

To get only transcripts, uncheck **MP4** and **MP3**, then choose **Transcript**. Pick **Plain text (.txt)**, **Timed captions (.srt)**, or **Both TXT and SRT**. A comma-separated list such as `en,de,pt-BR` selects languages. A base code such as `en` also matches regional tracks. Use `all` by itself to get every exposed caption language except live chat.

**Include auto-generated captions when available** allows tracks already generated by the source. Manual captions take precedence for the same language. The app does not generate transcripts from speech. If no matching convertible captions can be found, the queue and log report it. Do not confuse a port encounter with proof that a file was saved.

## Queue, save folders, and motion

- A fresh setup saves to `%USERPROFILE%\Downloads\Simple Pyrate`. The app creates `Video`, `Audio`, and `Transcripts` under the chosen folder as needed. **Browse** lets you change the destination.
- **Stop active** stops the running job, not the waiting queue. Finished files stay on disk. Unfinished media may leave a part file that can be resumed if the source supports it.
- **Remove selected** removes a waiting job. **Retry selected** retries a failed, stopped, or partial job. **Clear finished** clears rows, not files.
- **Saved files** lists files found or saved during this session. Double-click one to open it. **Ship’s log** shows downloader and app messages. The list, queue, and log reset on exit, but preferences are retained.
- **Motion** switches the voyage and progress effects between animated and static. **Sea sound** toggles the local ambience and is off on first launch. Fast transfers may finish before the scenes catch up. The visuals never delay the queue.

## What Shipyard installs

Shipyard checks the **system PATH** for `yt-dlp.exe`, `ffmpeg.exe`, `ffprobe.exe`, and `deno.exe`. FFmpeg and FFprobe must be in the same directory on that path. The check looks for the executables, not their versions. Update an old independently installed version through the method you originally used.

If a tool is missing, setup downloads the appropriate x64 or ARM64 release asset from [yt-dlp](https://github.com/yt-dlp/yt-dlp/releases), [FFmpeg Builds](https://github.com/FFmpeg-Builds/FFmpeg-Builds/releases), or [Deno](https://github.com/denoland/deno/releases). It checks the published SHA-256 and byte count before installation. The managed tool folder is `%ProgramFiles%\BGGG\Blackwake\bin`, and Shipyard adds only that managed directory to the machine PATH. App settings still use `%LOCALAPPDATA%\BGGG\Blackwake` so upgrades from the earlier app name can retain them.

**Refresh managed tools** updates only tools installed in the managed folder. It does not replace separately installed executables. An already-open terminal may need to be reopened to see the new PATH.

## Remove the app

1. Close Simple Pyrate and delete its extracted folder. This does not remove media saved elsewhere.
2. To reset preferences, delete `%LOCALAPPDATA%\BGGG\Blackwake`.
3. To remove the managed tools, edit **System Properties → Advanced → Environment Variables → System variables → Path** with administrator rights and remove only the full path to `%ProgramFiles%\BGGG\Blackwake\bin`. Then delete `%ProgramFiles%\BGGG\Blackwake`. Skip this step if you still want to use these tools elsewhere. This does not touch independently installed copies.

Use the app on media you have permission to save. It does not import browser sessions, ask for site credentials, or bypass DRM.

# Simple Pyrate v2.6.3

Release candidate for Windows and Android from The Background Gremlin Group.

## Windows

- Extract the portable ZIP and run `Start-Simple-Pyrate.cmd`. The package includes the existing Windows UI, voyage artwork, ship bells and music, plus its x64 and ARM64 runtime.
- **Settings → Source access** can use a signed-in browser where supported. Manual cookie and YouTube PO token options remain available. Browser sign-in does not generate a PO token.
- The active haul shows source-resolution steps. **Support the crew · XMR donation** takes you to the original wallet details.

## Android

- Tap the standalone APK on Android 10 or newer (ARM64 or x86-64). No companion runtime is required.
- The ship and port stay visible behind the deck controls, and the approved compact layout is unchanged.
- **Remember on this device** can protect previously imported source credentials so you can tap **Use sign-in** later. Android cannot read another app's sign-in directly.
- The runtime prepares in the background and yt-dlp can reuse extractor data. The donation address is one tap from Settings.

## Verification

- Verify the Windows ZIP, signed APK, and both matching source ZIPs with `Simple-Pyrate-2.6.3-SHA256SUMS.txt`.
- The Windows engine and local media exports passed under Linux PowerShell 7. The Android APK passed direct-DEX signature and package checks. Native Windows launch and installation of this exact APK were not tested here.
- The supplied Android APK has a different signing certificate from 2.6.2 and cannot replace it in place.
